# Last Ferry at 2 AM

A NEON TIDE story: a pixel-art romantic comedy with three chapters, five endings, and an optional hovercraft minigame.

[Play the game](https://yaqihou.com/last-ferry-game-test/)

English, Simplified Chinese, and Japanese text. English voice acting and five music tracks. Enable Sound to listen. Progress is saved in this browser.

This test repository contains the built static release. GitHub Pages publishes the root of main. To update it, run npm run build:static in the game source project and replace the generated game files here with the contents of release/, preserving this README and CREDITS.md. Include .nojekyll.

See CREDITS.md for asset credits; the font license is in fonts/OFL.txt.
